Daily preventive maintenance rounds are quick, structured inspections — typically 30 to 60 minutes — that keep your HVAC plant operating within design parameters and surface developing faults before they become costly failures. Each round combines visual observation with instrument readings logged against expected ranges. Complete this checklist at the start of every operational day and retain completed copies for your maintenance records.

<Note>
  Print this checklist for field use or import it into your Computerised Maintenance Management System (CMMS) as a recurring daily work order. Digital records are preferable for trend analysis and audit trails.
</Note>

<Tip>
  Report any reading outside the expected range — or any unusual noise, vibration, or odour — to your supervisor immediately. Do not wait until the end of the shift. Early intervention prevents plant downtime and refrigerant loss.
</Tip>

## 1. Chiller System

| # | Task | Equipment | Pass / Fail / Value | Technician Notes |
|---|------|-----------|---------------------|------------------|
| 1 | Record chiller leaving chilled water temperature (expected: 6–7 °C at design load) | Chiller unit / BMS | | |
| 2 | Record chiller entering chilled water temperature (expected: 11–12 °C at design load) | Chiller unit / BMS | | |
| 3 | Record suction pressure for R134a circuit (expected: 2.9–3.2 bar g at 4 °C evap) | Refrigerant gauge / BMS | | |
| 4 | Record discharge pressure for R134a circuit (expected: 9.5–11.5 bar g at 40 °C cond) | Refrigerant gauge / BMS | | |
| 5 | Check oil pressure differential across compressor (expected: 1.0–2.5 bar above suction) | Oil pressure gauge | | |
| 6 | Record compressor amp draw and compare against design full-load amps (FLA) | Clamp meter / BMS | | |
| 7 | Inspect sight glass for refrigerant flow — confirm clear flow, no bubbles under normal load | Sight glass | | |
| 8 | Check for refrigerant leaks at joints, valve packing, and evaporator headers (use electronic detector or logbook entry) | Full chiller circuit | | |
| 9 | Confirm chilled water pump(s) are running and duty/standby status is as expected | Pump control panel | | |
| 10 | Check chiller control panel for active alarms or fault codes; record any codes present | Chiller controller | | |
